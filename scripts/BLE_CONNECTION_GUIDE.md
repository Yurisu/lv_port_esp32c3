# BLE连接问题解决指南

## 问题说明

你的ESP32-C3设备是一个**键盘(HID)设备**,并且已经通过Windows配对连接。这会导致Python脚本无法连接到设备,因为:

1. Windows已经与设备建立了连接
2. Windows蓝牙堆栈占用了设备
3. 其他应用程序(如Python)无法再连接

## 解决方案

### 方法1: 使用Windows设置移除设备(推荐)

#### 步骤:

1. **打开Windows蓝牙设置**
   - 按 `Win + I` 打开设置
   - 点击 **设备**
   - 点击 **蓝牙和其他设备**

2. **移除ESP32-C3设备**
   - 找到你的设备(名称通常为: `VSchess-xxxxx`)
   - 点击设备
   - 选择 **移除设备**

3. **确认移除**
   - 点击确认按钮

4. **运行Python连接脚本**
   ```bash
   python ble_connect.py
   ```

### 方法2: 使用ble_unpair.py脚本

#### 步骤:

1. **运行设备管理脚本**
   ```bash
   python ble_unpair.py
   ```

2. **检查已配对设备**
   - 选择 `1` 列出所有已配对设备
   - 查看你的ESP32-C3设备是否在列表中

3. **移除设备**
   - 选择 `4` 检查并移除目标设备
   - 或选择 `3` 手动移除指定设备

4. **连接设备**
   ```bash
   python ble_connect.py
   ```

### 方法3: 使用诊断脚本

运行诊断脚本来测试连接:

```bash
python ble_test_simple.py
```

这个脚本会:
- 扫描设备
- 尝试连接
- 显示详细的诊断信息

## 常见问题

### Q1: 为什么必须移除已配对的设备?

**A:** Windows蓝牙系统设计上,当一个设备已经与系统配对连接后,其他应用程序无法直接连接到它。这是为了防止冲突。

### Q2: 移除后,我还能使用键盘功能吗?

**A:** Python连接后,你可以通过BLE特征发送和接收数据。但HID键盘功能(直接输入字符)需要使用HID配置文件,当前脚本主要使用FFE2特征进行数据传输。

### Q3: 如何让Windows和Python都能连接?

**A:** 在BLE设计中,一个设备在同一时间只能被一个客户端连接。你需要:
- **方案A**: 使用Windows连接用于HID键盘功能,使用Python连接用于数据传输(需轮流切换)
- **方案B**: 只使用Python连接,在Python中模拟HID功能

### Q4: 连接后键盘还能正常工作吗?

**A:**
- 如果已移除Windows配对: 键盘HID功能可能暂时不可用,直到你重新配对
- 如果保留Windows配对: Python无法连接

### Q5: 如何重新连接Windows键盘?

**A:**
1. 先断开Python连接(Ctrl+C)
2. 在Windows设置中点击"添加蓝牙设备"
3. 选择你的ESP32-C3设备
4. 配对后键盘功能恢复

## 技术细节

### BLE连接模式

1. **广播模式(Advertising)**
   - 设备主动广播自己的存在
   - 其他设备可以扫描到它
   - 这是连接的第一步

2. **连接模式(Connected)**
   - 设备与一个客户端建立连接
   - 数据可以在GATT特征上传输
   - 同一时间只能有一个连接

### GATT服务

你的设备提供的服务:

- **HID服务** (0x1812): 键盘输入功能
- **NUS服务** (FFE0): Nordic UART服务
  - FFE1: 写入特征(TX)
  - FFE2: 通知特征(RX) ← Python脚本使用这个

### 为什么FFE2?

FFE2是Nordic UART Service (NUS)的RX特征:
- 设备使用它发送数据到Python
- Python通过`start_notify()`监听此特征
- 设备调用`esp_hidd_send_nus_uart_data()`发送数据
