# BLE蓝牙连接工具

这是一个Python编写的蓝牙低功耗(BLE)设备连接工具,用于连接到ESP32-C3设备并访问FFE2特征。

## 功能特性

1. **扫描设备**: 扫描并列出附近可用的BLE设备
2. **已配对设备**: 列出系统中已配对的蓝牙设备
3. **连接设备**: 连接到指定的BLE设备
4. **FFE2特征**: 查找并操作FFE2特征(读取/写入/通知)
5. **服务枚举**: 列出设备提供的所有GATT服务和特征

### 操作步骤

#### 1. 扫描附近设备

- 选择选项 `1`
- 程序会扫描5秒钟并列出所有发现的BLE设备
- 显示内容包括: 序号、地址、设备名称、信号强度(RSSI)

```

----------------------------------------------------------------------
1      AA:BB:CC:DD:EE:FF  VSchess-xxxxx                -55
2      11:22:33:44:55:66  Unknown Device              -78
```

#### 2. 列出已配对设备

- 选择选项 `2`
- 在Windows上会显示系统已配对的蓝牙设备
- 其他系统可能不支持此功能

#### 3. 连接到指定设备

- 选择选项 `3`
- 输入要连接的设备MAC地址(例如: `AA:BB:CC:DD:EE:FF`)
- 程序会自动:
  - 连接到设备
  - 列出所有GATT服务
  - 查找FFE2特征
  - 尝试读取FFE2特征值
  - 尝试启用FFE2特征的通知功能

连接成功后显示:


## FFE2特征说明

FFE2是一个常见的16位UUID,常用于自定义数据传输。在项目中:

- **完整UUID**: `0000ffe2-0000-1000-8000-00805f9b34fb`
- **用途**: 通常用于Nordic UART Service (NUS)的RX特征
- **属性**: 通常支持读取、写入和通知

## ESP32-C3端配置

确保你的ESP32-C3设备已正确配置:

1. BLE功能已启用
2. 设备正在广播(Advertising)
3. NUS服务(FFE0)和FFE2特征已注册
4. MTU设置为470或更大

参考`main.c`中的配置:

```c
// 设置MTU为470
esp_ble_gatt_set_local_mtu(470);
```

## 常见问题

### Q: 找不到设备怎么办?

A: 
- 确保ESP32-C3设备已上电并运行
- 确保设备正在广播
- 检查设备是否已被其他设备连接
- 尝试增加扫描时间(修改代码中的`scan_duration`参数)

### Q: 连接失败怎么办?

A:
- 检查设备地址是否正确
- 确保设备未被其他设备连接
- 尝试重启ESP32-C3设备
- 检查蓝牙适配器是否正常工作

### Q: 找不到FFE2特征?

A:
- 确认ESP32-C3代码中已正确注册FFE2特征
- 检查服务的UUID是否匹配
- 使用选项1扫描时查看所有服务和特征

### Q: Windows上提示权限错误?

A:
- 以管理员身份运行PowerShell或CMD
- 确保Windows蓝牙服务已启用
- 检查Windows隐私设置中的蓝牙权限

## 技术说明

### 依赖库

- **bleak**: 跨平台的BLE客户端库
- **asyncio**: Python异步IO库

### FFE2特征操作

程序会自动执行以下操作:

1. **读取特征值**: 如果特征可读,会读取当前值
2. **启用通知**: 如果特征支持通知,会启用通知并设置回调
3. **数据接收**: 收到通知时会自动打印数据

### 连接参数

- MTU大小: 自动协商,最大支持517字节
- 扫描超时: 默认5秒
- 连接超时: 默认系统设置

## 扩展功能

如需添加更多功能,可以修改`ble_connect.py`:

### 写入数据到FFE2

```python
async def write_to_ffe2(self, data):
    """向FFE2特征写入数据"""
    if self.client and self.client.is_connected:
        await self.client.write_gatt_char(
            FFE2_CHARACTERISTIC_UUID,
            data,
            response=True
        )
        print(f"已写入数据: {data.hex()}")
```

### 读取FFE2特征

```python
async def read_from_ffe2(self):
    """从FFE2特征读取数据"""
    if self.client and self.client.is_connected:
        data = await self.client.read_gatt_char(FFE2_CHARACTERISTIC_UUID)
        print(f"读取到的数据: {data.hex()}")
        return data
```
